# 지하철 2호선 게임 — 수정사항 (2026-10-31)

## 수정한 내용

1. **먹보유령 포획 시 사다리게임만 실행**: 기존의 철로 탈출 사다리게임을 사용하며 추격 미로는 더 이상 발생하지 않습니다. 이전 버전에서 미로를 진행하던 세션도 사다리게임으로 전환합니다.
2. **먹보유령의 집과 등장 연출**: 성수역 근처의 집(🏠)에 눈(👀)을 내밀고 숨어 있으며, 5번째 전진 주사위 턴에서 집 밖으로 나와 노선으로 이동합니다. 집에서 나오기 전에는 뒤로 가기 주사위로 등장하지 않습니다. 한 번 등장한 뒤에는 계속 노선 위에 있습니다.
3. **KTX + SRT 결합 말 이미지**: 시작 화면의 말과 KTX/SRT 선택 시 움직이는 말은 두 열차의 기존 사진을 연결한 합성 이미지(`train_ktx_srt_connected_token.png`)로 표시됩니다. 무궁화호 말과 각 열차를 선택하는 사진은 유지합니다.

## GitHub / Streamlit 배포

기존 GitHub 저장소의 `PDF_merge.py`를 수정된 파일로 덮어쓰고, **새 파일인 `train_ktx_srt_connected_token.png`와 `train_ktx_srt_connected.png`를 추가**하면 됩니다. 기존 노선도와 열차 이미지 파일은 그대로 유지합니다.

Streamlit Community Cloud에서는 메인 파일을 `PDF_merge.py`로 설정합니다. `requirements.txt`는 변경하지 않았습니다.
