# 지하철 2호선 게임 — 수정사항 (2026-10-31)

## 수정한 내용

1. **먹보유령 포획 시 사다리게임만 실행**: 기존의 철로 탈출 사다리게임을 사용하며 추격 미로는 더 이상 발생하지 않습니다. 이전 버전에서 미로를 진행하던 세션도 사다리게임으로 전환합니다.
2. **먹보유령의 집과 등장 연출**: 성수역 근처의 집(🏠)에 눈(👀)을 내밀고 숨어 있으며, 5번째 전진 주사위 턴에서 집 밖으로 나와 노선으로 이동합니다. 집에서 나오기 전에는 뒤로 가기 주사위로 등장하지 않습니다. 한 번 등장한 뒤에는 계속 노선 위에 있습니다.
3. **KTX + SRT 결합 말 이미지**: 시작 화면의 말과 KTX/SRT 선택 시 움직이는 말은 두 열차의 기존 사진을 연결한 합성 이미지(`train_ktx_srt_connected_token.png`)로 표시됩니다. 무궁화호 말과 각 열차를 선택하는 사진은 유지합니다.

## 4차 보너스 미니게임 재설계 (8세 권장)

이번 업데이트는 보물상자 칸에서 진행하는 **9개 보너스 미니게임의 규칙·난이도·화면**을 전면 수정했습니다. 3차 랜드마크 말판 및 앞선 열차·먹보유령 변경은 그대로 유지합니다.

| 게임 | 새로운 도전 과제 | 발달·학습 요소 |
| --- | --- | --- |
| 탐험 가방 순서 추리 | 네 가지 단서로 물건 다섯 개의 순서를 추론 | 순서 추론, 논리 |
| 비밀 문 방향 암호 | 같은 방향·반대 방향 단서로 문 네 개의 방향을 찾아내기 | 관계 추론 |
| 반짝이는 별자리 | 선택한 별과 상하좌우가 동시에 반전되는 2×3 불빛 퍼즐 | 패턴, 계획 |
| 끊어진 다리 연결 | 3×3 타일을 돌려 출발점과 도착점의 경로 만들기 | 공간지각력 |
| 동물 카드 기억력 | 8장에서 네 동물 짝을 찾고 시도 횟수에 도전 | 작업기억 |
| 열쇠를 찾는 미로 | 6×6 미로에서 열쇠를 얻은 뒤 출구 찾기 | 경로 계획 |
| 동물 구조 뗏목 | 1·2·3·4·6kg 동물들을 양쪽 각각 8kg으로 분배 | 덧셈, 문제해결 |
| 비밀 색깔 암호 | 색과 자리 피드백을 이용해 3자리 비밀 암호 맞히기 | 논리, 추론 |
| 움직이는 숫자 퍼즐 | 실제로 숫자를 밀어야 하는 2×3 슬라이딩 퍼즐 | 공간적 계획 |

### 보상 및 진행 규칙

- 성공 점수: **30점(우수) / 20점(성공) / 10점(완주)**. 카드를 여러 번 뒤집거나 미로에서 길을 돌아가더라도 클리어하면 최소 10점을 받습니다.
- 정답 검사형 게임(순서 추리·비밀 문·별자리·다리·뗏목)은 총 4번 검사할 수 있으며, 틀린 검사 후에는 힌트가 표시됩니다. 보너스 게임을 풀지 못해도 기존 점수에는 영향을 주지 않습니다.
- 암호 추리는 최대 7번 정답 검사를 할 수 있고, 세 번 추리한 뒤 추가 힌트가 나타납니다.
- 카드·미로·숫자 퍼즐은 정답에 도달할 때까지 계속 조작할 수 있고 조작 횟수에 따라 보너스가 달라집니다.
- 5회·10회 연속 정답 시 발생하는 별도의 4개 보물상자 선택 이벤트는 **기존 방식 유지**.

## 5차 업데이트: 이벤트 로그 및 아이템 기능 삭제

- 게임판 오른쪽의 **이벤트 로그 패널**을 없애고, 로그 수집·전달·표시 로직도 제거했습니다. 현재 점수, 턴 수, 연속 정답, 열차, 유령 거리 및 칸 범례는 계속 표시합니다.
- **아이템 획득/보관/사용 기능**을 없앴습니다. 2배 이동 카드, 뒤로 가기 면제 카드, 점수 2배 카드와 해당 사이드바 버튼/안내는 더 이상 없습니다. 구버전 세션에 남은 아이템 상태도 자동으로 폐기됩니다.
- 파란 보너스 칸에서 기존 아이템 카드가 나오던 이벤트를 **즉시 +10점 보상**으로 변경했습니다. 나머지 파란 칸 이벤트(추가 주사위, 점수, 유령 후퇴)는 유지합니다.
- 정답 점수는 기본 +10점이며, **연속 정답 보너스**와 **5·10연속 특별 보물상자**는 그대로 유지합니다. 오답 시 아이템 면제 없이 뒤로 가기 주사위를 굴립니다.
- 앞선 3차 랜드마크 말판, 먹보유령 사다리게임, 집 등장 효과, KTX·SRT 말, 9종 보너스 게임은 변경하지 않았습니다.
- 테스트: `python -m unittest discover -s tests -v`와 Python/보드 JavaScript 문법 검사, 기존 게임·보너스 게임 시뮬레이션 통과. 실제 Streamlit 브라우저 통합 테스트는 수행하지 않았습니다.
